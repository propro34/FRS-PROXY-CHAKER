# FRS Proxy Chaker v5 - Master Edition

تطبيق فحص بروكسيات متكامل ومحسّن للاستضافة على المنصات السحابية مثل Render.

## المميزات الجديدة:
1. **مصادر جلب تلقائية (Auto Scraper):** يحتوي على 7 مصادر GitHub محدثة يومياً وبشكل تلقائي لجميع أنواع البروكسي (HTTP, HTTPS, SOCKS4, SOCKS5).
2. **خيارات فحص تلقائية (Google / Bing / Yahoo):** خيارات سريعة مدمجة لفحص الاتصال بـ Bing و Yahoo بالإضافة إلى Google و Cloudflare و HttpBin.
3. **أداء مستقر وبدون ثقل:** خوارزميات فائقة السرعة O(1) تضمن عدم تجمد المتصفح أو السيرفر.

## التشغيل المحلي:
```bash
npm install
npm start
```
